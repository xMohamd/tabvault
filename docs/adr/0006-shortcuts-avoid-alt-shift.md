# Keyboard shortcuts avoid Alt+Shift

The suggested shortcuts are Ctrl+Shift+L, Ctrl+Shift+. and Ctrl+Shift+, (Command on macOS).
Alt+Shift combinations look free but many systems use Alt+Shift to switch keyboard layout and
swallow the key press before the browser sees it. Keys the browsers already own (Alt+Shift+B in
Chrome, Ctrl+Shift+K/E/Y in Firefox, Ctrl+Shift+U for Unicode input on Linux) are avoided too.
Browsers apply suggested keys only on first install, so changing them later doesn't affect
existing users.
