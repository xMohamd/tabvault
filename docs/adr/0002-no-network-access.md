# No network access

TabVault never makes network requests and loads no remote code: no sync service, no analytics,
no update checks, no remote error reporting. Users trust it with their complete browsing state,
and a local-only design removes a whole class of privacy and security risks and makes store
review simpler. Features that would need a server (cloud sync, sharing links) are out of scope;
moving data between devices goes through Backup files the user controls.
